## 데이터
- 데이터는 프로그램이 처리하는 정보
- 데이터는 메모리(RAM)에 저장되어서 사용된다.
- 데이터는 연산, 출력, 저장의 대상이된다.

- 데이터의 종류 : 숫자, 문자, 문자열, 논리값

## 상수
- 프로그램 실행 중 값이 변하지 않는 데이터
- 메모리에 저장되며, 메모리에서 변할 수 없는 읽기 전용 값

### 리터럴 상수 : 값 자체
- 코드에 쓰인 숫자, 문자, 문자열
- 정수 상수 : 10
- 실수 상수 : 3.14
- 문자열 상수: "Hello"

### 기호 상수 : (이름이 붙은 상수)
- 변하지 않는 값을 의미 있는 이름으로 표현
- PI = 3.14
- Max_Score = 100
- 값은 리터럴이지만 이름을 붙여서 사용한다.

### 기호 상수 : 이름이 붙은 상수

## 변수
- 상수를 저장하는 곳의 이름
- eggs = 10 : eggs라는 이름에 15라는 값을 저장한다.

- 값을 대입하는 순간 자동으로 생성된다.

- 변수의 기본 동작의 흐름 (입력 -> 저장 -> 처리 -> 출력)

## 변수와 작성 규칙
- 첫 글자 
- 알파벳 또는 밑줄로 시작해야한다.
- 숫자로 시작할 수 없다.
- 이후 글자는 알파벳, 숫자, 밑줄을 사용할 수 있다.

- 사용할 수 없는 기호 : 특수 기호
- 대소문자 구분
- 지정된 문법 사용불가
- cammel-Case
- 대소문자 주의 : 구분함

## 좋은 변수명 작성
- 변수명을 잘 작성하면 프로그램 가독성을 좋게한다.
- 의미가 있는 변수명
- 변수의 역할이 이름만 보고도 알 수 있어야합니다.
- 한글 자 변수 최소화

## 변수의 생성과 값 변경
- 변수를 미리 만들거나 선언할 필요가 없다.
- 변수에 저장된 값은 다른 값으로 바꿀 수 있다.

## 메모리 (RAM)
- 컴퓨터가 작업중에 잠깐 저장하는 주 기억장치
- 필요한 값을 빠르게 저장하고 꺼내쓰는 공간
- 프로그램은 HDD 에 저장되지만 실행을 하면 메모리에 저장되고 CPU에서 처리하게 된다.
- 메모리는 엄청나게 많은 칸으로 구성된ㄷ
- 각 칸에서는 주소가 있따
- 주소는 몇번 칸인지 나타내는 번호이다
- 데이터는 주소를 통하여 저장하고 조회한다.
- 프로그램은 하드디스크에 저장
- 프로그램 실행시 프로세스와 데이터는 메모리에 저장된다.
- 하드디스크 -> 메모리 -> CPU

## 데이터
- 프로그래밍에서의 데이터 : 숫자 / 문자, 문자열 / 참거짓
- 메모리에서의 데이터 : BIT/8BIT = 1byte

## 변수는 메모리 공간에 붙인 이름
- num1 =10
- 숫자 10이 메모리 어딘가에 저장됨
- 변수 이름 num은 저장된 위치를 참조함.
- num2 = num1
- 즉 복사가 아닌 같은 값을 참조한다.

## 자료형
- 숫자형 : 정수 /실수
- 문자열 : 문자들의 집합
- bool : True/False (내부적으로 0/1 처리)
- 정수형 , 실수형 , 문자열 ,불리언
- 자료형확인 : 변수에 저장된 값의 자료형이 무엇인지 알아보는것
- type()은 저장된 값이 어떤 자료형인지 알려주는 함수이다.
